## Objective

Phase 4 estimates baseline model performance using nested stratified cross-validation on the LTMM harmonized dataset.

No model is declared superior; results are presented descriptively.

## Interpretation

Results are presented descriptively. Due to the small sample size (N=77),
fold-to-fold variability is expected and should be emphasized.
No model is declared superior based on any single metric.

TUG has been identified in Phase 2 as having the clearest association with cohort membership.
These Phase 4 results are exploratory and do not prove TUG alone is sufficient for prediction.

## Limitations

- Small sample size (N=77, 33 fallers) limits statistical power.
- Five positive events per predictor is below the traditional EPV=10 heuristic.
- Single dataset; no external validation performed.
- Limited feature set (5 predictors).
- Unresolved target semantics (cohort label vs clinical diagnosis).
- Unresolved gender coding direction.
- Unresolved fall-history leakage status.
- Hyperparameter selection via inner CV on N=77 has high variance.
