## Scientific interpretation

The target `HighFallRisk` aligns exactly with the cohort prefix (CO→0, FL→1). Until original LTMM documentation verifies whether this represents an independently validated clinical high-fall-risk score or simply the original Controls-vs-Fallers cohort label, the task is described as **cohort classification** rather than prospective fall-risk prediction.

TUG shows the clearest association with cohort membership, consistent with the exploratory findings from Phase 1.

No causal conclusions are drawn. All findings are exploratory and descriptive.

## Limitations

- Small sample size (N=77, 33 fallers) limits statistical power and generalizability.
- Five positive events per predictor is below the traditional EPV=10 heuristic.
- Shapiro-Wilk p-values are not used as the sole basis for test selection.
- The fall-history variable's temporal relationship to cohort assignment is unverified.
- No temporal design information is available in the CSV.

## Unresolved issues

1. Whether `HighFallRisk` represents a clinically validated high-fall-risk diagnosis or the original cohort label remains unverified.
2. Whether `سابفه سقوط` was part of the label assignment is unverified.
3. Retrospective vs prospective classification timing is undocumented.
4. The meaning of Gender coding (0 vs 1) is not documented.
5. Whether `Total x` equals normalized MMSE or `Totaly` equals PASE is unverified.
6. Gender code direction (which value corresponds to which sex) requires source documentation.
